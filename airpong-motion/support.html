AirPods Controls

For the intended experience, connect compatible AirPods with motion support, wear them, select them as the audio output if needed, then center head motion before starting a run.

If compatible AirPods are not connected, tilt fallback is available.

Game Center

Leaderboards and achievements require Game Center. If scores do not appear, confirm that Game Center is enabled on the device and that the device has a network connection.

Nearby Multiplayer

Nearby multiplayer requires local network permission, compatible app versions, and devices that can discover each other on the same local network.
